# media/ — public hosting for social clips

Finished marketing clips, published so that **schedulers can attach them by URL**.

The Metricool MCP (and most scheduling APIs) accept media **only as a public URL** — there is no file
upload — while the clips themselves live in each game's art repo, which is private/gitignored. So the
finished clips get copied here and served at:

```
https://chickvideogames.com/media/<game>/<clip>.mp4
```

GitHub Pages serves them with the correct `content-type: video/mp4`.

## Rules

- **Finished, public-ready clips only.** These URLs are world-readable. Never put raw footage, work in
  progress, or anything not already meant to be published here.
- **One folder per game** (`cbg/` = Cozy Block Garden).
- **Not linked from any page** and not in `sitemap.xml` — this is a file drop, not site content.
- **Keep the files after scheduling.** Metricool copies each video into its own storage at schedule time,
  so a scheduled post no longer depends on these URLs, but re-scheduling, hook variants and the next
  batch all need them again.

Source of truth for the clips + how they are produced: each game's art repo
(`<game>-art/marketing/clips/`, generated by `make_elevated_clip.py`).
Publishing process: `ChickVideoGames/guides/marketing/CONTENT-PUBLISHING-WALKTHROUGH.md`.
